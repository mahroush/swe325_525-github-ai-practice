## How I Used the GitHub Workflow

I used the GitHub issue to keep track of what needed to be completed for the assignment and to organize the main tasks.

I created a feature branch so I could work on the assignment without making the changes directly on the main branch.

I used separate commits to save the important changes I made along the way and to keep the project history easy to follow.

Once the work on the feature branch is finished, I will open a pull request so the changes can be reviewed before they are merged.

After the pull request is reviewed and completed, the final version of the work will be merged into the main branch.
